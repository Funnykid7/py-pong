**Goal:** Add a 1vCPU game mode with a reaction-delay + speed AI, restructure the main menu to offer 1v1 and 1vCPU, and add a difficulty select screen (Easy / Medium / Hard / Insane) that appears before mode select when CPU mode is chosen.

**Architecture:** A new `CPUController` class in `src/cpu.py` drives P2's paddle velocity each frame, replacing keyboard input when in CPU mode. A new `STATE_DIFFICULTY` state is inserted between `STATE_MENU` and `STATE_MODE_SELECT` for the CPU path. All new constants (params, colours, state name) live in `src/constants.py`; renderer gets two new draw functions; `game.py` wires the state machine and CPU update call.

**Tech Stack:** Python 3.12, pygame-ce, pytest

    ball.pos.y = 200.0
    paddle = _make_paddle()
    cpu = CPUController("MEDIUM")  # reaction_delay = 0.18s
    # Advance past the full delay in one step
    cpu.update(0.20, ball, paddle)
    assert cpu._target_y == ball.pos.y

    paddle = _make_paddle()

    cpu = CPUController("EASY")    # max_speed = 180
    cpu._target_y = HUD_HEIGHT     # target near top — maximum chase

```python
import pygame
from src.constants import SCREEN_H, HUD_HEIGHT, CPU_PARAMS
from src.entities import Ball, Paddle


class CPUController:
    def __init__(self, difficulty: str):
        params = CPU_PARAMS[difficulty]
        self.max_speed: float = params["max_speed"]
        self.reaction_delay: float = params["reaction_delay"]
        self.dead_zone: float = params["dead_zone"]
        self._reaction_timer: float = self.reaction_delay
        self._target_y: float = (SCREEN_H + HUD_HEIGHT) / 2.0

    def update(self, dt: float, ball: Ball, paddle: Paddle) -> None:
        center_y = (SCREEN_H + HUD_HEIGHT) / 2.0
        if ball.vel.x > 0:
            self._reaction_timer -= dt
            if self._reaction_timer <= 0:
                self._target_y = ball.pos.y
                self._reaction_timer = self.reaction_delay
        else:
            self._target_y = center_y
            self._reaction_timer = self.reaction_delay

        diff = self._target_y - paddle.pos.y
        if abs(diff) <= self.dead_zone:
            paddle.vel.y = 0.0
        elif diff < 0:
            paddle.vel.y = -self.max_speed
        else:
            paddle.vel.y = self.max_speed
```
