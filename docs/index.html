What's in the game

Built to feel alive

Every element of classic Pong redesigned with neon physics, screen shake, and a smash mechanic that changes momentum.

Signature Feature

Smash Meter

Builds during play - faster when you're losing. When charged, press LSHIFT or RSHIFT to activate: your paddle grows, your opponent shrinks. One charged strike per match cycle.

FX

Neon Effects

Ball trails, particle bursts on score, screen shake on impact - rendered with BLEND_ADD glow.

AI

CPU Opponent

Reaction-delay based AI from Easy to Insane. Single-player mode against a brain that reads the ball.

3x

Game Modes

First to 11, Best of 3 Sets, or Timed 3-minute match with sudden death overtime.

dt

Delta-Time Physics

Framerate-independent movement. Smooth 60 FPS on any machine, consistent on any hardware.

Game Modes

Three ways to play

Pick the format that fits your session.

01
Classic

First to 11

Continuous single match. No sets, no clock - first to eleven wins. The original Pong format.

11 points
02
Sets Format

Best of 3 Sets

Each set goes to 7 points. Win two sets to take the match. Momentum swings between sets give every game a second life.

7 pts per set
03
Timed

3 Minute Match

Most points in 3 minutes wins. Tied when the clock hits zero? Sudden death: next point ends it.

Sudden death OT

Four AI tiers.
One for every skill level.

The CPU uses reaction-delay simulation - it cannot respond faster than its tier allows. Insane plays in real time with zero delay. Easy gives you room to learn.

0.35s delay

0.18s delay

Controls

Two players, one keyboard.

Player 1 - Left

WMove up
SMove down
LSHIFTActivate smash

Player 2 - Right

↑Move up
↓Move down
RSHIFTActivate smash
ESCPause / Return to menu

Get it running

Install in 3 commands

# Clone the repository
git clone https://github.com/Funnykid7/py-pong
cd py-pong

# Install dependencies
pip install -r requirements.txt

# Launch
python main.py
